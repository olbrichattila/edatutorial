# Dead Letter Queue with RabbitMQ

YouTube ***(Hungarian)***: https://youtu.be/-_SSQ4oVaxA

In this episode, I introduce Dead Letter Queues (DLQ) using RabbitMQ. We’ll cover the core concepts and walk through a hands-on demo in the RabbitMQ Management Console. This episode does not include a code example on GitHub. In the next episode, we’ll integrate DLQ handling into our Golang codebase.
